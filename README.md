# 🖊️ EDITOR PDF by PARBUS

**Firma digital y herramientas PDF — 100% gratuito**

### ✨ Herramientas incluidas

| Herramienta | Descripción |
|-------------|-------------|
| ✍️ **Firma Digital** | Firma tus PDFs haciendo clic |
| 📝 **PDF a Word** | Convierte a .docx editable |
| 📊 **PDF a Excel** | Extrae tablas a .xlsx |
| 🖼️ **PDF a Imagen** | Cada página como PNG |
| 🗜️ **Comprimir PDF** | Reduce el tamaño del archivo |
| ✂️ **Dividir PDF** | Extrae páginas específicas |
| 🗑️ **Eliminar Páginas** | Quita páginas del documento |
| 🔄 **Rotar PDF** | Gira páginas 90° |
| 🖼️→📄 **JPG a PDF** | Crea PDF desde imágenes |
| 📝→📄 **Word a PDF** | Convierte .docx a PDF |
| 📊→📄 **Excel a PDF** | Convierte .xlsx a PDF |
| 📂 **Unir PDFs** | Fusiona varios PDFs en uno |

### 🛠️ Stack

- Python + Flask
- PyMuPDF (procesamiento PDF)
- pdf2docx (conversión Word)
- Interfaz responsive
